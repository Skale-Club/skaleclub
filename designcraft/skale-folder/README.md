# Skale Club folder — DesignCraft source

This directory contains the editable DesignCraft reconstruction of the live
Skale Club print folder (`/print/folder`). The source page is an A4 landscape
bi-fold with two pages (outside and inside) and 3 mm bleed.

Run `node build-folder.mjs` to rebuild the `.designcraft` document and PNG
proofs from the local assets in `assets/`.
